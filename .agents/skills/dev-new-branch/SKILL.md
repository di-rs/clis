---
name: dev-new-branch
description: Use when starting development work or creating a branch in this repository.
---

- Create `<type>/<short-name>`; type must be `feat`, `fix`, `chore`, `docs`, or `refactor`.
- Fetch origin and branch from `origin/master`; preserve existing uncommitted work.
- Reuse a matching branch for ongoing work. Never develop on `master` or use another prefix.
- Use the `gitmoji-commit` skill for every commit.

# true

Return success without output.

## Behavior

- Exits normally with status 0 without output.
- Ignores arguments and does not implement help/version flags.

## Example

From the workspace root:

```sh
cargo run -p true
```

Reference: GNU Coreutils manual for [true](https://www.gnu.org/software/coreutils/manual/html_node/true-invocation.html).
